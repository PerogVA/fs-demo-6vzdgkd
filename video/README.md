# Куда класть свои ролики

Положите mp4-файл в эту папку, например `priyomka.mp4`,
и укажите его в новости — `data/news.ts`:

```
video: {
  kind: "file",
  src: "/video/priyomka.mp4",
  poster: "/pages/pickup.jpg",   // обложка, необязательно
  caption: "Приёмка заказа за пятнадцать минут",
},
videoAfter: 1,                    // после какого абзаца показать
```

## Требования к файлу

- Формат **mp4** (кодек H.264 + AAC) — играет во всех браузерах.
- Размер по ширине 1280 или 1920 пикселей, больше не нужно.
- Вес: держите в пределах 30–50 МБ на ролик. Сайт статический,
  всё скачивается целиком, тяжёлые файлы будут долго открываться
  на мобильном интернете.
- Длинные ролики (больше пяти минут) лучше заливать на YouTube,
  VK Видео или Rutube и подключать по идентификатору — тогда
  вес сайта не растёт, а плеер грузится только по клику.

## Ролик с хостинга вместо файла

```
video: { kind: "youtube", src: "dQw4w9WgXcQ" }
video: { kind: "rutube",  src: "a1b2c3d4e5f6" }
video: { kind: "vk",      src: "oid=-123456&id=456789&hash=abc123" }
```

Для YouTube `src` — то, что стоит после `v=` в адресе.
Для VK параметры берутся из кода вставки.
